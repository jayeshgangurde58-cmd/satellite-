# OSCD dataset goes here

Download the official Onera Satellite Change Detection images, train-label and test-label archives from https://rcdaudt.github.io/oscd/ and extract all three here while preserving the archive's internal directory names. Do not commit the dataset to Git; image data have their own source terms.

The loader expects the official roots `Onera Satellite Change Detection dataset - Images`, `Onera Satellite Change Detection dataset - Train Labels`, and `Onera Satellite Change Detection dataset - Test Labels`.
